# TALLER-RECURSIVIDAD
RONNY FARID GUEVARA GALVIS
Descripción
Es una colección de 13 ejercicios en Java que resuelven problemas matemáticos y de arreglos usando recursividad. Todos siguen el mismo estilo: código limpio y principio DRY Cada programa es independiente, con su propio main, y lee los datos por consola, para ejecutalo se debe tener instalado el JDK (Java Development Kit) y se ingresa los datos que pida cada codigo para ver su funcionamiento.
